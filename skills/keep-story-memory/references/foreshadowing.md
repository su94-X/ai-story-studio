# 伏笔闭环

伏笔是给未来理解、选择或情绪留下有效信息，不等于任何重复道具，也不要求每场强塞提示。

## 判断承诺

确定信息何时能被观众察觉、人物如何理解、首次解释是什么、后续用途是什么。可以是因果规则、物件细节、人物策略、关系动作、视觉/声音模式或情绪呼应。

先计划再埋设：对主要结局或反转倒推必要信息，但不要为了结尾临时重写前文规则。证据足够、自然进入场景且承担当下作用时才算有效铺设。

## 随正文检查

- 首次出现是否可被看见/听见？是否有足够叙事条件让观众记住，而非藏在不可拍的心理描述中？
- 人物当时知道多少？主角不能在回收时无依据地知道观众曾看到的信息。
- 发展是否增加意义或代价？反复展示同一道具不自动算升级。
- 回收是否兑现原先承诺？局部解决、情绪回响和信息揭示分别说清，不把毫无因果的新事件当成回收。
- 反转后重看是否成立？误导依靠视角和解释差异，不能让客观正文造假。

## 返回给写作 Agent

对缺失铺设、过度明显、信息跳跃、错误回收或陈旧证据给出具体场次与修订方向。可以建议增加人物试探、调整线索可见性、改变揭示时机或让回收伴随有代价的选择；不直接改正文。

主创修订后重新登记，守护者验证实际替换文段及其后续影响。完成定稿时要求回收的线索都要有有效正文证据；不能只把 ledger 状态改为 paid_off。
