# 联网选材策略

## 搜索前

从用户约束建立检索范围：时间窗口、地区、语言、平台、受众、题材、作品形式。默认近7天、中文网络；本地时区未知用 `Asia/Hong_Kong`。将“最近7天”等相对时间展开为明确的起止日期；具体检索时刻按实际可获得的时间记录，无法取得精确时刻时只记日期和时区。

时间窗口限制用于来源和话题的新近程度，不等于故事必须发生在这7天。用户指定平台时说明检索覆盖，不将公开网页搜索描述为完整平台数据。

## 工具选择

1. 优先宿主可用的公开网页搜索与页面打开/抓取工具。调用前读取真实工具说明，遵守参数和批量数量限制。
2. 工具未暴露时，使用宿主提供的发现能力搜索相关工具；不存在发现能力就说明无法联网。
3. 可用平台榜单或官方API时读取实际数据；只有搜索时保留公开网页的覆盖限制。不得假定存在某个平台API、虚构请求URL、内置假搜索MCP或绕过登录。
4. 浏览器仅在宿主规则允许且确有必要时使用；普通信息查询优先搜索。无法打开页面时记录“仅搜索摘要”，不说已阅读全文。

## 有限检索流程

先用少量互补查询，避免无限扩散：

- 查询A：范围内的近期热点/社会或文化话题。
- 查询B：指定题材、受众或平台的相关近期讨论。
- 查询C：针对候选事件，寻找第一手说明、原始发布或权威报道。

搜索词按真实需求组成，不预设事件一定发生。并行查询遵守真实工具限制；后续核验依赖检索结果，顺序进行。

筛出约5—8条相关线索，打开关键来源，深核最有价值的线索后形成候选。证据已足够、重复检索无新增信息或存在明确访问限制时停止，并报告缺口。不要为凑满5个候选创造不存在的热点；可补充明确标注的原创方向。

## 时间、去重和核验

每条线索记录：

| 字段 | 记录规则 |
|---|---|
| 来源标题与URL | 使用实际检索结果或已打开页面的链接 |
| 发布者 | 原发布者、媒体、平台或作者；无法确认时标未知 |
| 事件发生时间 | 与报道时间分别记录；未知、不明确或存在争议时如实标注 |
| 报道/更新时间 | 页面实际显示的时间；页面更新时间不自动等同于事件时间 |
| 检索时间与时区 | 使用实际时间；注明内容可能变化 |
| 读取范围 | 全文、部分页面、摘要或榜单条目 |
| 事实与核验状态 | 已核实、仅单一来源、争议、未证实；说明依据 |

同一事件的转载、标题变化和镜像页面合并为一条事件。优先原始来源或第一手材料；多个转载不算独立证据。关键事实尽可能交叉核验；只有单一可靠来源时明确标注，不杜撰第二来源。

区分“新事件”“旧事近期再讨论”“旧事新报道”“时间未知”。旧事可作为题材，但不得冒充近期发生。

## 热榜与近期话题

只有实际读到榜单数据，才使用“排名”“热度指数”“讨论量”等描述，并记录平台、指标定义、数值和采集时间。不同平台指标不直接比较；榜单快照不代表未来热度。

有近期报道/讨论但没有可核验榜单数字时，标注“近期话题”。搜索命中数量、媒体转载数量和模型印象都不能替代平台热度数据。“热度持续性”只能写依据与不确定性，不能给伪造概率。

## 从事实到虚构

用三栏建立创作来源：

| 层次 | 示例表达 |
|---|---|
| 来源事实 | 某来源于某日发布了一项工作方式变化；具体事实以原文为准 |
| 情绪/困境解释 | 创作判断：这可能触及被替代、失去认可或承担责任的情绪 |
| 虚构方案 | 创作一个负责训练替代系统的虚构人物，让他的选择带来故事后果 |

不把推测写成事实，不把创作判断写成全体观众的态度。真实事件启发的新增人物、对白和情节明确标注为虚构。来源未知的许可不得变成“可自由改编”。

## 失败降级

- **无联网工具**：写“本次无法联网检索”，继续用户已提供材料或原创选材。
- **调用失败**：写实际失败或访问限制，使用成功取得的材料，标记覆盖不足。
- **登录/付费墙**：不绕过；利用可读部分并标注范围，或请求用户提供有权使用的内容。
- **只有摘要**：只提取摘要明确支持的线索，结论保持暂定；不编造全文细节。
- **证据冲突**：并列主要来源差异，避免用争议事实作为确定的故事依据。

交付时将来源链接放在相关事实旁或项目开发卡中，遵从宿主引用格式。引用短且必要，不大量复制原文。未经用户要求，不承诺定时搜索或后台自动更新。
