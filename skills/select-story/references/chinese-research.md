# 中文热点研究方法

检索策略由 Agent 根据作品目标制定。本文件提供可组合方法，不是固定榜单抓取器。

## 先分来源用途

| 来源类别 | 用于判断 | 使用边界 |
|---|---|---|
| 原始发布、机构说明、新闻报道 | 事件事实、时间与因果背景 | 转载去重；保留原始来源和读到的范围 |
| 微博、知乎、小红书等公开讨论 | 困境、关系冲突、不同立场和表达方式 | 单条评论不代表公众意见；不可访问时不编造讨论 |
| 抖音、快手、B站等公开视频或公开页面 | 视觉题材、故事表现、近期话题线索 | 页面标题不等于看过视频；没有视频读取能力则标注范围 |
| 实际可读取的平台榜单 | 该平台的排名、热度口径与采集时刻 | 无数据就标近期话题；不同平台数字不混算 |
| 长期社会议题 | 热点背后的可持续人物困境 | 与新近事件区分；不能冒充“今天热搜” |

平台名称是检索方向，不保证当前页面可访问。遇到登录、反爬或权限限制，换用合法公开报道或用户提供的材料，记录缺口。

## 时间与查询组合

默认近7天；用户可指定24小时、30天或其他范围。展开为明确日期和时区。短窗口寻找新事件，中窗口观察持续讨论，长窗口寻找反复出现的困境。来源时间无法确认时留空，不因搜索排序而认定新近。

选择少量互补查询，并随结果调整：

- 扫描：时间范围＋受众生活领域／题材。
- 定位：平台或发布者＋具体事件关键词。需要时使用真实搜索工具支持的站点限定。
- 核验：事件主体＋原始声明／报道／日期。
- 视角：同一困境的不同角色处境，寻找冲突双方的可理解目标。
- 降噪：排除转载和同一事件的标题变体，不把营销稿数量当成自然热度。

不要只用一条“最近热门事件”查询就宣称覆盖中文互联网。也不要为了广度无限搜索；来源已足够支撑候选、重复无增量或有明确访问限制时停止。

## 从话题形成题材

每个值得开发的线索记录：事实与未知、讨论中的不同立场、可见情绪依据、可持续人物困境、时效性、需要虚构的部分。受众情绪是有依据的创作判断，不做无证据的民意统计。

可以开发不同方向，例如同一“智能设备改变家庭关系”的线索，分别以照护者、被照护者或服务人员为主角。差异要落实到目标、行动、代价和结局，不能只换姓名。

选材比较仍使用故事轴与制作轴；热度只是输入背景。记录题材的新鲜度、差异化和为何适合目标形式，避免把热度转换成成功率。

## 可恢复研究记录

已初始化项目时用 source 类型记录保存来源编号、URL、时间、读取范围、事实支持和争议；用 index 类型保存候选与来源之间的定位关系。原文长资料作为项目原稿登记，索引保留必要短引；不大量复制网页到每次上下文。

研究记录与虚构故事分别保存。后续剧情不能反向修改来源事实。
