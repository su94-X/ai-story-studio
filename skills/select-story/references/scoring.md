# 选材双轴评分

评分用于比较当前候选，是基于现有梗概和制作条件的编辑判断。不是流量、收益或成功率预测。分别展示故事轴与制作轴，不计算混合总分；用户偏好会影响最终推荐，但不能改写已发现的难点。

## 故事轴：吸引力与叙事成立程度

| 分数 | 锚点 |
|---|---|
| 1 | 只有话题或设定，主角目标、行动和结果不清楚，去掉标签后难以成立 |
| 2 | 有人物与冲突，但行动被动、代价薄弱，开场或结尾需要大幅改造 |
| 3 | 目标—阻力—选择—后果成立，有明确情绪回报；仍有差异化或结构问题 |
| 4 | 冲突具有递进，关键选择影响结局，视觉和人物关系提供明确特色，最小展开较完整 |
| 5 | 现阶段展开证实核心卖点贯穿开场、行动与结尾；差异化、情绪兑现和目标形式适配都强，主要结构疑点已处理 |

检查维度：一句话故事清晰度、人物主动性、选择与代价、开场推动力、冲突递进、结尾兑现、视觉叙事、与同批候选的差异。给出整体锚点分及1—3条决定性依据，不用多个小分平均掩盖核心缺陷。

## 制作轴：当前条件下的可实现程度

| 分数 | 锚点 |
|---|---|
| 1 | 核心场面高度依赖当前未具备或未验证的能力，替代方式会破坏主要卖点 |
| 2 | 多个核心场面或一致性要求缺乏可行方案，需要明显重构或新资源 |
| 3 | 在明确约束和少量改造下可规划制作，关键疑难场面仍需样片验证 |
| 4 | 多数场面适配已有工具与资产，困难镜头已有保留故事作用的替代方式，复用路径清楚 |
| 5 | 核心场面已有实际测试或同条件资产证据支持，叙事表达与制作方案匹配，仍保留正常执行余量 |

信息不足时不打“容易制作”的高分。可以给条件分，如“3分，前提是确认角色一致性方案”；若关键条件完全未知，标“待评估”，不要假装精确。

检查维度：角色/服装/空间一致性、多人互动、连续动作、因果可读性、物体接触、特定文字/界面、对白与声音、镜头衔接、资产复用、实际工具/团队能力。均按具体场面分析，不给任何题材永久禁令。

## 证据与置信度

每轴单独标注置信度：

- **高**：关键故事节点已展开，或对应制作能力有当前实际测试/可复用证据；大部分判断依据可指认。
- **中**：有明确梗概、结构或工具条件，但部分核心节点/镜头未验证。
- **低**：依赖不完整输入、主观假设、旧工具信息或未测试的核心能力。

来源事实的可信程度与故事评分置信度分开。已核实新闻不能自动提高故事评分；故事精彩不能提高事实可信程度。每个弱点说明“会影响什么”和“怎样验证/改造”，无需伪造数值置信概率。

## 动态AI能力配置

记录：工具/版本（已知才填写）、测试日期、已验证能力、未验证能力、已有角色/场景/音色资产、后期能力、用户可接受的复杂度。工具能力变化或制作条件变化时更新配置和制作评分。

具体场面用以下方法改造：

| 原要求 | 可探索的替代方式 | 必须保留的故事作用 |
|---|---|---|
| 长时间多人连续动作 | 分拆单人反应、局部动作与后果画面，用剪辑连接 | 谁做了什么、结果如何 |
| 精确屏幕文字 | 单独制作界面/文字并后期合成，或用声音/人物行动传递 | 观众获得的关键信息 |
| 大规模群体事件 | 主角视角、场外声音、局部证据、风格化意象 | 压力规模与人物代价 |
| 复杂变形/时空变化 | 明确前后状态、过渡意象、有限重复的视觉规则 | 转变的意义与规则可读性 |

上述仅为候选方法，不保证具体工具可完成。若替代方案抹掉故事核心，降低制作适配并改造故事或暂缓。

## 推荐规则

用“双轴分数＋关键依据＋形式适配＋用户偏好”决定推荐。档位可用“优先开发”“改造后开发”“暂缓”。说明推荐成立的条件和最大未验证点。高故事分、低制作分项目可作为后续资产/能力提升方向；不自动淘汰。

同时评估AI的视觉价值：它能否让梦境、时空错位、风格化空间、非日常意象等成为叙事证据，而不是只增加装饰？视觉价值有助于推荐，不能覆盖薄弱因果。
