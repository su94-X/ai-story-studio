# 短片与连续短剧的选材验证

先服从用户的形式与时长，未指定时给出适配判断。体裁可以喜剧、悬疑、情感、奇幻、科幻、现实等；体裁名称本身不能决定故事分或制作分。

## 独立短片

检查一个核心问题能否在目标时长内完成：

1. 主角的初始处境和目标是否可见？
2. 什么事件迫使他行动？阻力是否真实改变行动？
3. 关键选择有什么失去的风险或代价？
4. 结局是否由行动产生，而不是只靠解释、巧合或最后增加规则？
5. 结尾是否回收开场、伏笔或情绪？开放结尾也需要兑现主要问题。

可使用的5节点结构：初始欲望 → 触发与行动 → 阻力和代价 → 关键选择 → 后果与回收。结构允许调整，不能机械要求等时长或固定反转。

短时长优先检查角色数量、场景切换、规则解释与情绪弧的容量。若删去设定后无法说明人物选择，先修正故事。用可见动作与画面传达核心信息，对白负责关系和策略，避免旁白承担所有因果。

## 连续短剧

设定之外必须有“持续产生冲突的机制”：人物关系、利益目标、制度/规则、调查链或持续任务如何让一个问题的解决引出下一个问题？

最低验证：

- **系列主线**：主角长期目标、终局方向与主要代价。
- **冲突来源**：至少两种后续推进机制，不能仅重复同一误会或拖延揭晓。
- **关系升级**：人物选择使信任、权力、合作或对立发生变化。
- **前三集**：每集有实际行动、信息/情绪回报和局势变化；结尾期待来自已发生的后果。
- **阶段结局**：阶段问题得到处理，后续问题与此前行动有因果关联。
- **故事容量**：用户集数是否有足够内容；不足时建议缩短、合并或新增有作用的主线。

每集钩子可以是选择、代价、揭示、目标改变或关系变化，不要求每集机械反转。观众应得到回报，不能只有“下集再说”。未指定集数时用阶段方案和前三集验证，不直接制造大量分集剧情。

## 形式选择

| 候选特征 | 可能适配 | 需验证的问题 |
|---|---|---|
| 一次不可逆选择、完整情绪变化 | 短片 | 结尾是否由选择产生，篇幅是否足够 |
| 持续关系博弈、长期目标和逐级代价 | 连续短剧 | 每阶段是否有变化而非重复 |
| 只有一个反转或视觉奇观 | 极短片或扩展前提 | 人物行动、情绪回报是否成立 |
| 庞大设定、多人支线、规则密集 | 改造后再判断 | 能否聚焦主角、减少解释并保留卖点 |

同一故事可转形式，但应明确改造：短片转短剧需要新增持续冲突机制；短剧压成短片需要选择一个阶段和关键决定，不能只删对白。

## 同批差异与热点去标签

候选至少在下列一项有实质差异：人物关系结构、冲突机制、情绪目标、叙事视角、结局选择或视觉规则。仅换姓名、职业、城市或性别不算新选题。

将热点名称替换为通用处境后重述一句话故事。若无法写出主角的行动和代价，说明它仍是话题评论。可继续开发，但应先补上可见行动、具体对手/阻力和不可轻易撤销的后果。
