# 戏剧结构参考

把结构当作诊断工具，按类型、时长和用户风格调整，不给所有故事套同一节奏。

## 人物驱动

| 要素 | 写作问题 | 可观察的验证 |
|---|---|---|
| 目标 | 人物此刻想拿到、阻止或保住什么？ | 能指出正在争取的具体结果 |
| 必要性 | 为什么今天必须行动？ | 拖延会失去机会、利益或关系 |
| 阻力 | 什么让目标难以实现？ | 人物改变策略仍有真实成本 |
| 选择 | 哪两个有代价的方向无法兼得？ | 行动体现取舍，不能靠一句感悟代替 |
| 后果 | 选择改变了什么？ | 新局面能被画面、关系或行为证实 |

给主角可用的能力和明确局限。让对手、同伴拥有自己的目标，即使他们不在画面中也遵循同一动机。人物可以失败、妥协或拒绝改变，但结局必须回应其行动。

## 短片

围绕一个主冲突，按实际篇幅分配以下功能；多个功能可以合并在一场内：

1. **建立承诺**：出现一个值得关注的人、异样、愿望或困境。
2. **触发行动**：事件使原有状态无法维持。
3. **尝试与升级**：主角的办法产生新代价或揭露更深阻力。
4. **关键选择**：此前积累的信息迫使主角决定。
5. **结果与回收**：呈现行动后果，兑现主要情绪与线索。

结尾可以留未解的世界问题，但不能遗漏故事的主问题。短片篇幅有限时，压缩背景解释和次要支线，保留选择发生所需的信息。

## 连续短剧

先写一句可持续运作的机制，例如：“每次帮助一名客户消除记忆，主角就失去一段自己的记忆；这些损失逐渐指向她曾参与的事件。”这个机制还需要人物目标、变化空间与季终方向，不能只重复同一种事件。

建立三层推进：

- **全季线**：主目标、累计代价、人物关系变化与季终兑现。
- **阶段线**：几集形成一次不可逆变化、阶段胜负或信息回收。
- **单集线**：当集目标、阻力、决策与结果。

设计分集表时记录：本集前后的局势差、人物关系差、信息差。每一集至少改变一项，同时使整个阶段靠近结果。逐集产生新处境，避免只更换阻拦者。

续集期待应来自已发生的结果，如人物付出代价、错误承诺被揭穿、关系立场改变。不要在角色即将回答时机械切断，也不要以未发生且无后果的惊吓充当全部结尾。

## 信息、悬念与反转

- 区分观众知道什么、每个人物知道什么、事实是什么；追踪每项信息的出现位置。
- 用知情差、期限、目标冲突或行动风险构建悬念。不要用所有人隐瞒显然应该说出的信息维持剧情。
- 反转前埋可回看的线索，反转后改变行动或关系。纯粹增加新规则不算回收。
- 核对伏笔的铺垫、误导与兑现。误导不能让镜头或客观叙述捏造事实，除非作品已建立非可靠叙述机制。

## 场景诊断

为场景填写一行：“谁想要什么 → 遇到什么可见阻力 → 做了什么 → 局面怎样变化”。

场景无变化时，判断是否承担必要设定、情绪停顿或线索功能。若没有，删除或合并；若有，把信息放在具体行动中。对白场也要有人试图改变对方，不能只交换背景资料。

## 制作与戏剧作用

先记录难场面的戏剧作用，再选表现方法。例如“拥挤地铁中的追逐”可能承担追捕压力与错失关键人物；若项目不能制作大规模追逐，可改成关闭车门、隔窗目光、站台脚步与丢失道具，只要保留相同信息和后果。

不要把所有困难场面都改成旁白，也不要只因AI生成方便添加不服务故事的幻境。视觉奇观必须推进情绪、信息或人物选择。
