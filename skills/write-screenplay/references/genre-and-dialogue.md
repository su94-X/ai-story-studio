# 类型、人物与对白方法

先读取用户目标、已有正文与锁定条件。按当前问题选择方法，不把所有技巧塞进每个故事，也不把类型当固定公式。

## 人物与关系

为主角明确外在目标、内在需要、害怕失去的东西、惯用策略和盲点。用实际选择验证这些特征，避免只填写人物小传。对手和同伴也要有自己的目标及可理解的理由。

关系变化可以来自信任、权力、利益、责任、亲密或债务。逐场问：人物利用了什么关系筹码？行动之后谁掌握了新的信息或主动权？连续短剧要让关系承受累计后果，不能每集重置。

## 类型化诊断

| 类型 | 重点方法 | 常见失效与修复 |
|---|---|---|
| 悬疑 | 区分事实、观众知情、人物知情；用可回看的线索支持揭示 | 只靠隐瞒正常人应说的话：改为利益冲突、证据不完整或真实风险 |
| 喜剧 | 建立人物策略与环境规则，让策略的坚持制造升级和代价 | 连续堆梗：让笑点改变局势，保留角色的认真目标 |
| 情感 | 用行为、让步、失约或共同任务表达关系；给双方可理解需求 | 只靠长段告白：把核心感情落在有成本的行动中 |
| 现实题材 | 保持生活细节与制度压力可信；人物拥有有限但真实的选择 | 主题压倒人物：让观众通过具体处境理解观点 |
| 科幻／奇幻 | 界定规则、成本、边界与例外；让规则迫使人物选择 | 结尾新增万能规则：提前建立限制，回收已铺设的信息 |

混合类型时明确主要情绪承诺。笑点、反转或视觉奇观要服务当前冲突；不要求固定秒数内必有反转。

## 对白修订

先确定每个人此刻想让对方做什么。台词可承担试探、隐瞒、讨价还价、威胁、安抚或改变关系；说话方式随地位和情境变化。

检查四件事：

1. 删除姓名后，能否从策略、句长、词汇与节奏区分角色？
2. 台词是否重复画面，或解释双方都知道的背景？把必要信息放入行动与分歧。
3. 表面谈什么、真正争取什么？潜台词需要上下文可读，不能让人物故意说谜语。
4. 沉默、打断、改口是否改变场面？有作用才写，避免给每句加情绪提示。

可以对关键场做一轮朗读式检查，按人物目标修订。估算时长仍需计入反应与动作，不把朗读速度当最终成片时间。

## 短片与连续短剧

短片优先完成一个核心选择及情绪回收。开场、升级与结尾可以通过同一道具、行动或声音形成变化，而非单纯重复。

连续短剧同时维护全季目标、阶段兑现与单集变化。记录每集前后的关系、局势和信息差；钩子来自当集结果，不以机械截断替代回报。续写前读取前集终点、角色已知信息和仍有效的伏笔计划。

## 修订方法

先修复结构、动机和信息，再润色句子。保留用户锁定核心；说明有实质影响的调整。涉及旧设定的变更，同步原稿版本和项目索引，由 story-keeper 检查受影响的后续集数。
