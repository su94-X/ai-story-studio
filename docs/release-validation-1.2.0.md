## 能力边界

写后自动流程是主创 Agent 遵循 Skill 的调用行为，不是后台文件监听或脚本替代创作判断。专职角色配置已经生成，当前会话的真实独立审稿使用可用子 Agent；没有在新会话验证 story-reviewer 原生角色加载，没有宣称自动 Hook 触发已验证。

平台能力资料是导入 Skill 中标日期的参考起点；本次文学稿试验不依赖其限额，未核验现时平台上限，未提交任何生成请求。
